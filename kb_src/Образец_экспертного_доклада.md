# Образец экспертного доклада ЦГЦУ по выполнению показателя

О чём: эталонная СТРУКТУРА и СТИЛЬ аналитического ответа по показателю доклада
ЦГЦУ (на примере «Доля грузовых отправок в груженых вагонах, доставленных в
срок»). Используй как образец того, КАК оформлять ответ — порядок блоков,
ссылки на источники, формулировки. Числа бери ТОЛЬКО из БД, не из этого образца.

## Принципы оформления (применять всегда)

- Ответ — на русском языке, человеческими формулировками. Внутренние имена
  столбцов и таблиц базы (day_fact, month_fact, zone, row_level и т.п.) в текст
  ответа не попадают: пиши «факт за сутки», «с начала месяца», «красная зона».
- Каждый блок данных сопровождай ССЫЛКОЙ НА ИСТОЧНИК в скобках: название справки
  или вкладки доклада, например «(источник — справка о наличии задержанных
  поездов)», «(источник — Доклад СКИМ ОД, срок доставки п.2.1)».
- Если показатель не достигает целевого значения за все три периода (сутки,
  с начала месяца, с начала года) — прямо укажи: «показатель находится в красной
  зоне риска». Цвет зоны бери из данных и пиши словом (красная / жёлтая / зелёная).
- Каждый блок начинай с периода: «В отчётные сутки…» / «С начала месяца…».
- Названия дорог — всегда полное имя (Дальневосточная, а не ДВС/ДВОСТ).
- Числа сопровождай нормой/планом и динамикой к прошлому году, отклонения — в
  п.п. или %, как в данных.

## Объём ответа по типу вопроса

- Вопрос вида «проанализируй показатель / представь результаты» → дай ТОЛЬКО
  шаг 1 (констатация по трём периодам со ссылкой на источник). Это и есть полный
  ответ. Шаги 2–4 НЕ добавляй без отдельной просьбы.
- Вопрос «причины / факторы невыполнения» → шаг 2 (и при необходимости шаг 3).
- Вопрос «конкретные цифры по источникам» → шаг 3.
- Вопрос «предложи решения / мероприятия» → шаг 4.

## Структура аналитического разбора (по запросу — шаги 2–4)

### 1. Констатация выполнения показателя (три периода) — основной ответ
По состоянию на <дата> показатель <имя> составил <факт за сутки> %, что <ниже/выше>
плана на <…> п.п. и <ниже/выше> уровня прошлого года на <…> п.п.
С начала месяца — <…> %; с начала года — <…> %.
Вывод о зоне риска (если цель не достигнута за все периоды — красная зона риска).
(источник — Доклад СКИМ ОД, вкладка срок доставки)

### 2. Причины и факторы невыполнения (качественно) — по запросу «причины»
Невыполнение обусловлено совокупностью внешних и внутренних факторов: отказы
техсредств, ограничения пропускной/перерабатывающей способности, нарушения
технологии перевозочного процесса, влияние внешних участников (грузополучатели,
порты, погранпереходы). Перечислить ключевые причины списком.

### 3. Конкретные цифры по источникам (каждый — со ссылкой) — по запросу «цифры»
Привести фактические показатели по каждому релевантному источнику, у каждого —
ссылка на справку:
- Припортовые станции: выгрузка факт против перерабатывающей способности, худшие
  станции. (источник — справки о работе припортовых станций)
- Техническая и участковая скорость по сети и дороги с наибольшим невыполнением.
  (источник — справки о выполнении скорости)
- Важнейшие сортировочные станции: простой транзитного вагона с переработкой и
  рабочий парк против норматива. (источник — справка по сортировочным станциям)
- Отказы техсредств 1-2 категории: всего, динамика к прошлому году, по комплексам
  (локомотивный/инфраструктурный). (источник — КАСАНТ, справка об отказах)
- Ограничения скорости, не предусмотренные графиком. (источник — АСУ ВОП-2)
- Отставленные (задержанные) поезда: всего по сети, по дорогам, по кодам
  ответственности ОАО РЖД (коды 43/21/22/1). (источник — справка о задержанных)
- Локомотивы: недосодержание парка по полигонам. (источник — АРМ ОНД, справка Локомотивы)

### 4. Управленческие решения по вводу показателя в целевое значение — ТОЛЬКО по прямому запросу «предложи решения/мероприятия»
Комплекс мероприятий: повышение качества планирования поездной работы; усиление
оперативного контроля за продвижением вагонопотоков; приоритетность подъёма
отставленных поездов; адресная работа со станциями с наибольшими перепростоями;
взаимодействие с грузополучателями и портами; повышение пропускной/перерабатывающей
способности; устранение ограничений скорости; повышение надёжности техсредств.
Рекомендации формулируй осторожно («целесообразно», «рекомендуется»).
