# ГЦУ Ассистент — Документация

**Система искусственного интеллекта для анализа ежедневных оперативных докладов Главного центра управления (ГЦУ) ОАО «РЖД».** Позволяет задавать вопросы на естественном языке о показателях, отклонениях, красных/жёлтых/зелёных зонах, задержках поездов, отказах техники, локомотивном парке, грузовой работе и других оперативных метриках.

## Быстрый старт

```bash
cp .env.example .env          # заполнить секреты
docker compose up -d           # запустить все 5 контейнеров
# http://localhost:3000        # чат-интерфейс
# http://localhost:8810        # страница загрузки докладов
```

## Технологический стек

| Слой | Технологии |
|---|---|
| **Бэкенд** | Python 3.11, FastMCP, Flask, Uvicorn |
| **База данных** | PostgreSQL 16 + pgvector + pg_trgm |
| **AI-интерфейс** | Open WebUI (чат), LM Studio (инференс) |
| **Модели** | Qwen3.6-35B-A3B MoE, Qwen3.6-27B, Qwen3.5-9B |
| **Эмбеддинги** | text-embedding-multilingual-e5-large-instruct (1024d) |
| **Инфраструктура** | Docker Compose (5 контейнеров) |

## Масштаб данных

- **62 доклада** (март 2022 + апрель 2026)
- **20 355 строк** оперативных показателей
- **10 033 строки** инвестиционных метрик
- **15 395 строк** текстовых комментариев
- **1 892 чанка** базы знаний
- **143 кода** подразделений (телеграфный справочник)
- **Сотни строк** справок-источников (задержки, отказы, локомотивы, порты, скорости)
