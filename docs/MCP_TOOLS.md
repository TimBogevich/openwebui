# MCP-сервер — API инструментов

MCP-сервер (`gcu/mcp_postgres_server.py`) предоставляет 6 инструментов для AI-модели через протокол Model Context Protocol (Streamable HTTP). Адрес: `http://gcu-mcp:8808/mcp`.

---

## Инструменты

### 1. `describe(table)` — описание схемы таблицы

Возвращает структуру таблицы «на лету» из системного каталога PostgreSQL: колонки с типами, комментарии, количество строк, диапазоны и образцы значений.

**Параметры:**
- `table` (str, по умолчанию `"metrics"`) — имя таблицы в схеме public

**Особенности:**
- Для основной таблицы (`metrics`) дополнительно показывает:
  - Список всех таблиц в базе
  - Диапазон дат `report_date` (мин-макс)
  - Таблицы `spravki_*` с их покрытием по датам и назначением
- Для низкокардинальных колонок (≤40 значений) — полный список
- Для высококардинальных — случайные примеры
- Числовые и служебные колонки не раскрываются (не нужны для написания WHERE)

**Защита:** максимум 2 вызова `describe` за вопрос (включая разные таблицы). При превышении — возврат ошибки с требованием перейти к SQL.

### 2. `query(sql)` — выполнение SQL

Выполняет read-only SELECT/WITH запрос и возвращает результат в текстовом виде (таблица с разделителями `|`).

**Параметры:**
- `sql` (str) — SQL-запрос (только SELECT/WITH)

**Ограничения:**
- Запрещены INSERT/UPDATE/DELETE/DROP/ALTER/CREATE/TRUNCATE/GRANT/MERGE
- Лимит отображения: 50 строк

**Защитные механизмы:**

**A. Защита от повторных запросов (dup-query guard):**
Кольцевой буфер из 12 последних хешей (MD5 от нормализованного SQL). При 3-м идентичном запросе — предупреждение, при 4-м — блокировка с требованием ответить на основе уже полученных данных.

**B. Защита от «ловли нулей» (zero-result fishing):**
Если 2 последовательных запроса вернули 0 строк — блокировка с требованием признать отсутствие данных.

### 3. `current_datetime(timezone)` — текущая дата/время

Фиксирует галлюцинации модели о текущей дате.

**Параметры:**
- `timezone` (str, по умолчанию `"Europe/Moscow"`) — IANA-зона

**Возвращает:** строку вида «Сегодня 8 июня 2026 года, понедельник. Время: 14:30 (Europe/Moscow).»

### 4. `weather(city)` — погода

Получает текущую погоду через Open-Meteo API (бесплатный, без ключа).

**Параметры:**
- `city` (str, по умолчанию `"Москва"`) — название города

### 5. `search_knowledge(query, k, collection)` — RAG по литературе

Поиск по справочной литературе РЖД (ПТЭ, учебники, справочники). Возвращает релевантные фрагменты с указанием источника.

**Параметры:**
- `query` (str) — запрос на русском
- `k` (int, 1–6, по умолчанию 3) — количество фрагментов
- `collection` (str) — фильтр: `''` (все), `'pte'`, `'textbooks'`, `'reference'`, `'glossary'`

**Механизм поиска:** гибридный Reciprocal Rank Fusion (RRF) — комбинация:
1. Векторного сходства (cosine, HNSW)
2. Русского полнотекстового поиска (tsvector)
3. Буст для курируемых коллекций `reference` и `glossary` (+0.010 к RRF)

**Эмбеддер:** `text-embedding-multilingual-e5-large-instruct` (1024d). Конвенция e5-instruct:
- Запрос: `"Instruct: Given a question, retrieve passages that answer it\nQuery: {query}"`
- Пассажи: без префикса (заэмбеджены bare)

**Усечение по длине:**

| Коллекция | Лимит символов |
|---|---|
| reference | 4000 |
| glossary | 2500 |
| pte | 2600 |
| textbooks | 600 |

### 6. `find_indicator(query, k)` — семантический поиск показателя

Ищет показатели в `metrics` по СМЫСЛУ запроса с использованием эмбеддингов. Замена перебора `name ILIKE '%...%'`.

**Параметры:**
- `query` (str) — вопрос или ключевое выражение («задержанные отправки», «участковая скорость», «погрузка угля»)
- `k` (int, 1–10, по умолчанию 5) — количество кандидатов

**Возвращает:** список кандидатов с similarity, номером показателя, разделом, единицей измерения, наличием разбивки по дорогам.

**Защита:** максимум 2 вызова за вопрос.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `GCU_DATABASE_URL` | `postgresql://postgres:...@127.0.0.1:5432/postgres` | Строка подключения к PostgreSQL |
| `FASTMCP_HOST` | `0.0.0.0` | Хост MCP-сервера |
| `FASTMCP_PORT` | `8808` | Порт MCP-сервера |
| `KB_EMBED_URL` | `http://host.docker.internal:1234/v1/embeddings` | URL эмбеддера |
| `KB_EMBED_MODEL` | `text-embedding-multilingual-e5-large-instruct` | Модель эмбеддинга |
| `KB_SNIPPET_CHARS` | `800` | Лимит символов по умолчанию |

## Защита от циклов (anti-loop guards)

Основная проблема MoE-моделей (Qwen 35B) — повторение одного и того же SQL-запроса 4-6 раз перед ответом. Сервер имеет три независимых защиты:

| Защита | Механизм | Порог |
|---|---|---|
| Dup-query guard | MD5-хеши в кольцевом буфере (12 последних) | 3-й повтор = WARN, 4-й = BLOCK |
| Zero-result fishing | Счётчик последовательных пустых результатов | 2 пустых = BLOCK |
| Describe cap | Счётчик вызовов `describe()` | >2 = BLOCK |
| find_indicator cap | Счётчик вызовов `find_indicator()` | >2 = BLOCK |

Все счётчики сбрасываются автоматически при блокировке (пользователь может продолжить).
