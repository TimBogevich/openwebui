# Бенчмарки и тестирование

## Методология

Проверка ответов модели осуществляется факт-чекингом (сверкой с PostgreSQL), а не субъективной оценкой. Каждый числовой ответ верифицируется прямым SQL-запросом к базе данных.

python db/test_runner_15.py

python db/test_runner_40.py

Раннеры отправляют вопросы модели через Open WebUI API, записывают tool calls, ответы и факт-чекают их.

## Результаты (последние)

### Qwen 35B MoE — 40Q бенчмарк

**Общий результат:** 18/40 (45%)

Без защиты от повторных запросов модель повторяла идентичный SELECT 4-6 раз на сложных аналитических вопросах — это основной бутылочное горлышко, а не качество данных.

После внедрения dup-query guard: +4 выигрыша, -4 регрессии (регрессии — из-за недетерминизма LLM при temperature=0.2, guard не срабатывал на них).

### Gemma 26B (a4b-qat) — 15Q бенчмарк

**Результат:** 7/15 (3 ленивых отказа — модель не вызывала инструменты).

Qwen выигрывает и по точности (8/15 vs 7/15), и по скорости (1.63 с/вызов vs 2.80 с/вызов).

### Известные проблемы моделей

| Модель | Проблемы |
|---|---|
| Qwen 35B MoE | Повторяет запросы 4-6 раз на сложной аналитике. Думает на английском в `<think>` |
| Qwen 27B | Лучше следует инструкциям, медленнее MoE |
| Qwen 9B | Сдаётся после первой ошибки SQL, выдумывает имена таблиц, путает латиницу/кириллицу |
| Qwen Coder 32B | **НЕ РАБОТАЕТ** как агент — пишет SQL текстом, не вызывает инструменты |

## Ручная верификация

Факт-чекинг конкретных значений:

```sql
-- Красная зона на 2022-03-01: должно быть 88
SELECT count(*) FROM metrics
JOIN reports ON metrics.report_id = reports.id
WHERE reports.report_date = '2022-03-01' AND zone = 2;

-- Максимальная скорость по дорогам на 2022-03-01
-- Должно быть: Дальневосточная 1368.556
SELECT road, max(month_fact) FROM metrics
JOIN reports ON metrics.report_id = reports.id
WHERE reports.report_date = '2022-03-01' AND road IS NOT NULL
GROUP BY road ORDER BY max(month_fact) DESC LIMIT 1;
```

## Оставшиеся рычаги улучшения

1. **Harness-level guard** против повторных запросов (внедрён в MCP-сервер)
2. **Temperature = 0.0** для чистого сравнения до/после
3. **Dense 27B** вместо MoE — лучше следует инструкциям, но медленнее
4. **Accept and ship** — основная масса оперативных вопросов работает корректно
